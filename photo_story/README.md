# A Story of Us — Photo Memories 🌸

A romantic, cinematic, and interactive web storytelling page crafted with love.

## ✨ Features
- **Grand Living Florist Bouquet Engine**: Realistic layered golden sunshine & sapphire blue chrysanthemums with natural wind sway and satin ribbon fluttering.
- **Atmospheric Background Canvas**: Tranquil floating blooms (hydrangeas, peonies, English roses, chrysanthemums, and sakura blossoms) with particle stardust and mouse-interaction physics.
- **Fast HTML-Aware Typewriter Engine**: Natural, satisfying typing cadence across all sentimental paragraphs and captions.
- **Infinite Romantic Music Player**: Continuous background music with floating vinyl disc controller and equalizer tooltip.
- **Polaroid 3D Parallax & Memory Slideshow**: Interactive tilt effects on cards and a cinematic final montage reel.

## 🚀 How to Host on GitHub Pages (Gratis & Mudah)

### Cara 1: Upload Langsung via Web GitHub (Tanpa Perlu Terminal)
1. Buat repository baru di GitHub (contoh: `a-story-of-us` atau nama bebas), centang **Public**.
2. Buka repository tersebut di browser, klik tombol **"Add file"** > **"Upload files"**.
3. Tarik (*drag & drop*) seluruh isi folder ini (`index.html`, `style.css`, `script.js`, folder `images/`, dan folder `audio/`) ke browser lalu klik **"Commit changes"**.
4. Buka menu **Settings** pada repository > pilih tab **Pages** (di sidebar kiri).
5. Pada bagian **Build and deployment** > **Branch**, pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu sekitar 1–2 menit, link website online Anda akan langsung aktif (contoh: `https://username.github.io/a-story-of-us/`)!

---

### Cara 2: Lewat Terminal / Git CLI
```bash
git init
git add .
git commit -m "Initial release: A Story of Us"
git branch -M main
git remote add origin https://github.com/<USERNAME>/<REPO-NAME>.git
git push -u origin main
```
Setelah itu aktifkan **GitHub Pages** di menu **Settings > Pages > Branch: main**.
